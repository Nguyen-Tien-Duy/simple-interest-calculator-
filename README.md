# Simple Interest Calculator

A simple script to calculate the interest earned on a principal amount over a period of time.

## Description
This project is a part of the open-source contribution exercise for the Google/IBM Coursera course. It provides a basic tool to compute simple interest based on user inputs.

## Formula
The simple interest is calculated using the formula:
**A = P(1 + rt)**

Where:
- **P** = Principal amount (Số tiền gốc ban đầu)
- **t** = Time period in years (Thời gian tính bằng năm)
- **r** = Annual interest rate (Lãi suất hàng năm)

## Usage
1. Provide the input values for Principal, Rate, and Time.
2. The calculator will output the calculated interest.
